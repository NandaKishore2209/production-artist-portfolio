# Production Artist Portfolio — Nanda Kishore

A recruiter-focused portfolio for Production Artist opportunities, centered on artwork review, quality assurance, revisions, production readiness and clear communication.

## Why this portfolio exists

Production artwork is not only about making something look good. The critical job is making sure the final artwork matches the brief and can move into production without avoidable errors.

This portfolio demonstrates a structured workflow:

**Brief → Artwork Review → Issue Identification → Revision → Final QA → Handoff**

## Role alignment

## Case studies

### 1. Apparel Artwork QA

A fictional apparel order is reviewed against a client brief. Issues are identified, categorized and resolved before final approval.

### 2. Artwork Revision

A revision request is translated into concrete visual changes, followed by a second QA pass.

### 3. Print-Readiness Checklist

A reusable checklist covers dimensions, placement, spelling, consistency, color considerations, file organization and handoff.

> These are portfolio exercises, not client work. They are intentionally presented as practice case studies so the portfolio does not misrepresent professional experience.
