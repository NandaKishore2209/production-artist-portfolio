# Case Study 03 — Print-Readiness Checklist

**Type:** Portfolio practice exercise  
**Objective:** Show the final checks performed before artwork handoff.

## Pre-production checklist

### Content
- [ ] Correct customer wording
- [ ] Correct spelling and punctuation
- [ ] Correct artwork/version

### Layout
- [ ] Correct placement
- [ ] Correct print dimensions
- [ ] Correct alignment
- [ ] Consistent spacing and typography

### Artwork
- [ ] Vector artwork where appropriate
- [ ] No accidental hidden/extra elements
- [ ] No unintended clipping
- [ ] Colors reviewed for the intended production method

### Handoff
- [ ] File name is unambiguous
- [ ] Correct final version supplied
- [ ] Production notes included where necessary
- [ ] Final QA completed after the last revision

## Decision rule

If an item is ambiguous, do not guess silently. Flag the issue and ask a clear clarification question. Accuracy is more valuable than creating a fast but incorrect handoff.
