# Case Study 02 — Artwork Revision

**Type:** Portfolio practice exercise  
**Objective:** Demonstrate how revision notes are converted into controlled artwork changes.

## Revision request

Create a fictional revision ticket containing 3–5 concrete changes, for example:

- Move the graphic 0.5 inch higher
- Reduce print width
- Correct one word in the artwork
- Match the approved font treatment
- Remove an unintended element

## Revision process

1. Read every instruction before editing.
2. Convert each instruction into a checkable item.
3. Make only the requested changes unless another production issue is discovered.
4. Reinspect nearby elements after each change.
5. Compare the revised artwork with the original brief.
6. Complete final QA before marking the ticket ready.

## Evidence to add

- Before artwork
- Revision notes
- Annotated corrections
- After artwork
- Final QA checklist
