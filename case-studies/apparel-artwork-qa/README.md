# Case Study 01 — Apparel Artwork QA

**Type:** Portfolio practice exercise  
**Objective:** Demonstrate a repeatable review process for apparel artwork.

## Scenario

A fictional campus apparel order requests a front-chest print with a specific phrase, garment color and approximate print size.

## QA checklist

- [ ] Customer wording matches the approved request
- [ ] Spelling and punctuation are correct
- [ ] Artwork is aligned to the intended print area
- [ ] Artwork dimensions match the order specification
- [ ] Typography is consistent
- [ ] Elements are not unintentionally clipped
- [ ] Artwork is suitable for the intended decoration process
- [ ] File naming and version are clear
- [ ] Final revision has been reviewed after editing

## Issues to simulate

Use a practice vector file to introduce controlled problems such as incorrect sizing, off-center placement, a spelling error and inconsistent typography. Document each issue and the correction.

## Final handoff

The final page should show:

1. Original artwork
2. Annotated issue list
3. Revised artwork
4. Final QA checklist
5. Production notes

This exercise demonstrates decision-making and QA discipline; it is not represented as client work.
