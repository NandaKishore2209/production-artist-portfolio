01 · PROFILE

Built for detail-heavy production work.

I approach visual work as a checklist-driven quality process: understand the brief, inspect the artwork, identify anything that can cause an incorrect result, make the required revision, and verify the final output before handoff.

My technical background in web development has also trained me to work systematically, follow specifications, debug issues and communicate clearly with teammates.

02 · PRODUCTION WORKFLOW

From client request to final QA.

02

03

04

Final QA

Run a repeatable checklist before handoff so speed never replaces accuracy.
